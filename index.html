GITHUB REPOSITORY

GitHub & Version Control

🌐 Visit GitHub:

Open GitHub.com to create your developer account and store your projects.

What is a Repository?

  • It is a secure online digital storage folder for all your project files and media.
  • It tracks revision histories and version control as your code changes over time.
  • It enables multiple developers to review, contribute, and build software together.

⚠️ Important Developer Note:

Although AI tools often provide code in one single block or file, it is vital to structure your project into separate files (`index.html`, `style.css`, `script.js`) before uploading to GitHub repositories. This ensures that collaborators and version control systems can track changes accurately!

APP DEPLOYMENT

Why Deploy Instead of Share Links?

⚠️ The Problem with AI Chat Share Links:

  • Chat session preview links are temporary and eventually stop functioning.
  • If chat servers go down or session limits expire, your app becomes inaccessible.
  • To share your app reliably with friends and teachers, professional cloud deployment is required.

TESTING ACROSS DEVICES

Testing Your Deployed Dynamic App

🔍 Steps to Verify Real-Time Database Sync:

  • 1. Copy your live deployed Netlify/Vercel URL.
  • 2. Open the link across 3 different browsers (e.g. Chrome, Safari, Edge) or share with your teacher.
  • 3. Make form entries and submit posts through all browsers.
  • 4. Go back to your Firebase Cloud Database console and observe the live records syncing in real time!
